# Student Grading System

This project is a simple Student Grading System developed in Java using Object-Oriented Programming (OOP) concepts. It allows users to input student details and marks, calculate the average score, and assign a grade based on performance.

## Features
- Input student roll number and name
- Enter marks for three subjects
- Calculate average marks
- Assign grade using if-else conditions
- Display complete student result

## Concepts Used
- Classes and Objects
- Encapsulation (private variables)
- Methods for input, calculation, and output
- Conditional statements (if-else)
- User input using Scanner

## How It Works
The program creates a `Student` object and takes input from the user. It then calculates the average marks and assigns a grade based on predefined conditions. Finally, it displays the complete result including student details, marks, average, and grade.

## Technologies
- Java (Core Java)
